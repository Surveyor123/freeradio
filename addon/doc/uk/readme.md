# FreeRadio — додаток для NVDA
- Переклад: Георгій Галас.

FreeRadio — це додаток для прослуховування інтернет-радіо, призначений для екранного зчитувача NVDA. Його головна мета — надати користувачам простий доступ до тисяч інтернет-радіостанцій. Весь інтерфейс та всі функції розроблені з урахуванням повної доступності для NVDA.

## Каталог Браузер радіостанцій

FreeRadio використовує відкриту базу даних [Браузер радіостанцій](https://www.radio-browser.info/) для свого каталогу станцій. Браузер радіостанцій — це безкоштовний каталог, яким керує спільнота і який містить понад 50 000 інтернет-радіостанцій з усього світу. Реєстрація чи обліковий запис не потрібні, а його API відкритий для всіх. Кожна станція містить інформацію про адресу, країну, жанр, мову та бітрейт; станції сортуються за вподобаннями користувачів. FreeRadio підключається до цього API через дзеркальні сервери, розташовані в Німеччині, Нідерландах та Австрії; якщо один сервер недоступний, він автоматично перемикається на наступний.

Щоб браузер залишався швидким і не навантажував API під час кожного пошуку чи зміни країни, FreeRadio зберігає на диску локальний кеш каталогу станцій. Цей кеш автоматично оновлюється у фоновому режимі за періодичним розкладом, тому список, який ви бачите, зазвичай уже актуальний без жодних дій з вашого боку. Ви також можете в будь-який момент примусово запустити негайну повторну синхронізацію кнопкою **Оновити список станцій** — див. розділ «Браузер радіостанцій» нижче.

## Додавання станції до Браузера радіостанцій

Якщо станція, яку ви шукаєте, відсутня в каталозі Браузера радіостанцій, ви можете додати її самостійно за адресою [https://www.radio-browser.info/add](https://www.radio-browser.info/add). Обліковий запис чи реєстрація не потрібні.

Заповніть форму на цій сторінці:

- **URL потоку** *(обов'язково)* — прямий URL аудіопотоку, що закінчується на `.mp3`, `.aac`, `.ogg` або подібне. Це не адреса веб-сайту станції; це адреса самого потоку, яку ви вставляєте в медіаплеєр. Більшість станцій публікують URL свого потоку на своєму веб-сайті або в розділі «Слухати в прямому ефірі».
- **Назва станції** *(обов'язково)* — назва станції, як вона має з'являтися в каталозі.
- **Головна сторінка** — адреса веб-сайту станції.
- **Країна та мова** — виберіть країну та мову з комбінованих списків.
- **Теги** — ключові слова жанру або теми, розділені комами, наприклад `новини`, `джаз`, `класика`. Вони використовуються для пошуку та фільтрування.
- **URL логотипу** — пряме посилання на зображення логотипу станції, якщо воно є.

Після надсилання станція проходить перевірку та додається до публічного каталогу. Після затвердження вона автоматично з’явиться у пошуку FreeRadio та списках країн, оскільки каталог оновлюється з API в режимі реального часу.

## Встановлення

Завантажте файл `.nvda-addon`, натисніть на ньому Enter і перезапустіть NVDA, коли буде запропоновано.

## Комбінації клавіш

Усі комбінації можна перепризначити в меню NVDA → Параметри → Жести вводу → FreeRadio. Ці комбінації працюють будь-де, незалежно від того, який діалог сфокусований.

| Комбінація | Функція | Опис |
|---|---|---|
| `Ctrl+Win+R` | Відкрити браузер радіостанцій | Відкриває діалог браузера радіостанцій, якщо він закритий, або виводить його на передній план, якщо він вже відкритий. |
| `Ctrl+Win+P` | Пауза / відновлення | Зупиняє поточну станцію, якщо вона відтворюється; відновлює, якщо була призупинена. Якщо нічого не відтворюється, запускає останню станцію або відкриває список улюблених залежно від ваших налаштувань. Подвійне натискання одразу переходить до вибраної вкладки. Триразове натискання виконує окрему дію залежно від вашого налаштування. |
| `Ctrl+Win+S` | Зупинити | Повністю зупиняє поточну станцію та скидає плеєр. |
| `Ctrl+Win+→` | Наступна улюблена | Переходить до наступної станції у списку улюблених. У кінці списку переходить на початок. |
| `Ctrl+Win+←` | Попередня улюблена | Переходить до попередньої станції у списку улюблених. На початку списку переходить у кінець. |
| `Ctrl+Win+↑` | Збільшити гучність | Збільшує гучність на 5; максимум 200. |
| `Ctrl+Win+↓` | Зменшити гучність | Зменшує гучність на 5; мінімум 0. |
| `Ctrl+Win+V` | Додати до улюблених | Додає станцію, що зараз відтворюється, до списку улюблених. Повідомляє, якщо станція вже є у списку. |
| `Ctrl+Win+I` | Інформація про станцію | Повідомляє назву станції, що зараз відтворюється. Натисніть двічі, щоб у діалозі показати деталі, такі як країна, жанр та бітрейт. Натисніть тричі, щоб скопіювати інформацію про поточний трек (метадані ICY) до буфера обміну, якщо вона доступна; якщо метадані відсутні, замість цього запускається розпізнавання музики Shazam. Натисніть чотири рази, щоб примусово запустити розпізнавання музики у разі неправильних метаданих ICY. |
| `Ctrl+Win+M` | Дзеркальний показ аудіо | Одночасно дзеркально показує потік на додатковий пристрій виведення аудіо. Натисніть ще раз, щоб зупинити дзеркальний показ. |
| `Ctrl+Win+E` | Миттєвий запис | Натисніть один раз, щоб почати запис поточної станції; натисніть ще раз, щоб зупинити. Натисніть **двічі**, щоб почати **запис треку** — файл отримає назву поточного треку, а запис автоматично зупиниться, коли трек зміниться. Натисніть двічі, поки запис треку активний, щоб зупинити його достроково. Відтворення продовжується без перерв у всіх режимах запису. Доступно лише для станцій, що транслюють метадані ICY. |
| `Ctrl+Win+W` | Відкрити папку записів | Відкриває папку із записаними файлами у Провіднику файлів. |
| `Ctrl+Win+J` | Тайм-шифт — перемотування назад | Перемотує живе радіо на 15 секунд назад. Перше натискання активує режим тайм-шифту; кожне наступне перемотує ще на 15 секунд назад, до межі буфера (~10 хвилин). Потребує увімкненого буфера тайм-шифту в Налаштуваннях. |
| `Ctrl+Win+K` | Тайм-шифт — перемотування вперед | Перемотує на 15 секунд вперед у режимі тайм-шифту. Досягнувши краю прямого ефіру, відтворення автоматично повертається до прямого ефіру, і команда не має ефекту до наступного перемотування назад. |
| `Ctrl+Win+T` | Увімкнути/вимкнути буфер тайм-шифту | Миттєво вмикає або вимикає буфер тайм-шифту, відображаючи стан прапорця в Налаштуваннях. При вимкненні негайно повертає до прямого ефіру (якщо активний тайм-шифт) та зупиняє фонове захоплення. |
| *(непризначено)* | Увімкнути/вимкнути сповіщення про вимкнення звуку | Увімкнути або вимкнути налаштування «Сповіщення про вимкнення звуку» миттєво. Призначте комбінацію клавіш через меню NVDA → Параметри → Жести вводу → FreeRadio. |

Клавіші «Наступний» та «Попередній» призначені лише для навігації по списку улюблених станцій; вони не працюють зі списком усіх станцій. Коли у діалозі браузера радіостанцій виділено список, клавіші зі стрілками вліво та вправо виконують одну й ту саму функцію — див. «Клавіші швидкого доступу в діалогах».

## Браузер радіостанцій

FreeRadio також додає підменю **FreeRadio** до меню «Інструменти» NVDA. Звідти ви можете безпосередньо відкрити браузер станцій та налаштування FreeRadio.

Діалог, що відкривається за допомогою комбінації клавіш `Ctrl+Win+R`, містить п’ять вкладок: «Усі станції», «Улюблене», «Запис», «Таймер» та «Улюблені треки». Переміщатися між вкладками можна за допомогою комбінації клавіш `Ctrl+Tab`.

Коли відкривається вкладка «Усі станції», 1000 станцій, що набрали найбільшу кількість вподобань, автоматично завантажуються з браузера радіостанцій. Вибір країни зі списку оновлює список, показуючи станції цієї країни. Введення тексту в поле пошуку миттєво  виконує повний пошук по всій базі даних браузера радіостанцій одночасно за назвою, країною та жанром.

Комбінований список **Пристрій виводу** у нижній частині діалога браузера радіостанцій — поза вкладками — містить список усіх аудіопристроїв, розпізнаних BASS. Вибір пристрою негайно перенаправляє аудіовивід на нього та зберігає вибір назавжди; той самий пристрій автоматично використовується в наступній сесії. Якщо вибраний пристрій не підключено, додаток автоматично повертається до системного значення. Цей елемент керування працює лише тоді, коли активний бекенд BASS.

Елементи керування **Гучність** (0–200) та **Ефекти** у цій же області можна налаштовувати в будь-який час, поки діалог відкритий. У списку ефектів можна одночасно ввімкнути хор, компресор, спотворення, ехо, фленджер, булькання, реверберацію, еквалайзер: підсилення низьких частот, еквалайзер: підсилення високих частот та еквалайзер: підсилення вокалу; зміни миттєво застосовуються до активного потоку. Кожен ефект також можна миттєво вмикати чи вимикати комбінаціями від `Ctrl+1` до `Ctrl+0`, не відриваючи рук від клавіатури — див. розділ «Комбінації клавіш для ефектів» нижче. Ці елементи керування повністю функціонують лише тоді, коли активний бекенд BASS.

Коли ввімкнено один або кілька ефектів еквалайзера, для кожної активної смуги з’являється **регулятор підсилення**. Рівень посилення можна встановити в діапазоні від −15 дБ до +15 дБ; початкове значення — «Баси» +9 дБ, «Високі частоти» +9 дБ та «Вокал» +6 дБ. Регулятори посилення відображаються лише для тих смуг еквалайзера, які наразі позначені, і автоматично приховуються, коли ефекти еквалайзера знімаються. Значення посилення зберігаються глобально та відновлюються під час наступної сесії.

Кнопка **Відтворення/Пауза** також розташована внизу діалога. Якщо жодна станція не відтворюється, вона запускає вибрану станцію; якщо станція вже відтворюється, вона призупиняє відтворення.

Кнопка **Оновити список станцій** негайно повторно синхронізує локальний каталог станцій з API браузера радіостанцій, замість того щоб чекати на періодичне фонове оновлення. Поки оновлення виконується, кнопка недоступна, а NVDA оголошує, що оновлення триває; якщо натиснути її ще раз до завершення поточного оновлення, NVDA повідомить, що оновлення вже виконується. Після завершення оновлення NVDA оголошує, що список станцій оновлено, а поточні результати пошуку чи список за країною автоматично оновлюються, відображаючи нові дані.

Коли станція вибрана у списку, кнопка **Інформація про станцію** показує таку інформацію, як країна, мова, жанр, формат, бітрейт, веб-сайт та URL потоку в окремому діалозі. Кожне поле показується у власному текстовому полі, доступному лише для читання; ви можете переходити між полями за допомогою клавіші Tab та скопіювати всю інформацію до буфера обміну одночасно за допомогою кнопки **Копіювати все до буфера обміну**. Ця кнопка доступна як на вкладці «Усі станції», так і на вкладці «Улюблене».

### Контекстне меню станції

Клацніть правою кнопкою миші на станції у списку «Усі станції» або «Улюблене», або виберіть її та натисніть клавішу контекстного меню чи `Shift+F10`, щоб відкрити контекстне меню зі швидкими діями:

- **Інформація про станцію** — те саме, що й описана вище кнопка «Інформація про станцію».
- **Додати до улюблених** *(вкладка «Усі станції»)* / **Видалити станцію** *(вкладка «Улюблене»)*.
- **Перейменувати станцію** *(вкладка «Улюблене»)* — те саме, що й `F9`.
- **Зберегти аудіопрофіль для цієї станції** / **Очистити аудіопрофіль** *(вкладка «Улюблене»)* — див. Аудіопрофіль станції.
- **Перевірити URL** — перевіряє, чи наразі доступний потік вибраної станції, не запускаючи відтворення, та оголошує результат (доступно, або причину збою, наприклад, помилку HTTP чи тайм-аут мережі).

Показуються лише пункти, що стосуються поточної вкладки та вибору.

### Комбінації клавіш у діалозі

Наступні клавіші працюють лише тоді, коли діалог Браузера радіостанцій активний.

### Клавіші F

| Комбінація | Функція | Опис |
|---|---|---|
| `F1` | Довідка | Відкриває файл довідки додатка у браузері. Спочатку здійснюється пошук довідки для мови, яка використовується в NVDA; якщо її не знайдено, відкривається довідка початковою мовою. |
| `F2` | Що зараз відтворюється | Оголошує назву станції та треку, що зараз відтворюються. Натисніть двічі, щоб у діалозі показати детальну інформацію, таку як країна, жанр та бітрейт. Натисніть тричі, щоб скопіювати інформацію про поточний трек (метадані ICY) до буфера обміну, якщо вона доступна; якщо метадані відсутні, замість цього запускається розпізнавання треків Shazam. Натисніть чотири рази, щоб примусово запустити розпізнавання музики у разі неправильних метаданих ICY. |
| `F3` | Попередня станція | Переходить до попередньої станції на вкладці «Усі станції» або «Улюблене» та негайно починає відтворення. Переходить до кінця, якщо знаходиться на початку списку. |
| `F4` | Наступна станція | Переходить до наступної станції у вкладці «Усі станції» або «Улюблене» та негайно починає відтворення. Переходить до початку, якщо знаходиться в кінці списку. |
| `Shift+F3` | Попередній канал | Тільки на вкладці «Подкасти»: переміщення на один канал вгору у списку підписок. |
| `Shift+F4` | Наступний канал | Тільки на вкладці «Подкасти»: переміщення на один канал вниз у списку підписок. |
| `F5` | Зменшити гучність | Зменшує гучність на 5 (мінімум 0). |
| `F6` | Збільшити гучність | Збільшує гучність на 5 (максимум 200). |
| `F7` | Пауза / продовження | Призупиняє відтворення, якщо станція відтворюється; продовжує відтворення, якщо вона була призупинена і медіа завантажено. |
| `F8` | Зупинка | Повністю зупиняє поточну станцію та скидає плеєр. |
| `F9` | Перейменувати | Відкриває діалог перейменування для станції, що знаходиться у фокусі на вкладці «Улюблене». |

### Список комбінацій клавіш для навігації

| Комбінація | Функція | Опис |

## Улюблене

Список улюблених — це особиста колекція радіостанцій, яка зберігається постійно. Щоб додати радіостанцію, виберіть її у списку та натисніть кнопку «Додати до улюблених» або скористайтеся комбінацією клавіш `Alt+V`. Ця ж комбінація клавіш видаляє радіостанцію, яка вже є у списку, після її вибору.

До улюбленого можна перейти за допомогою комбінацій клавіш `Ctrl+Win+→` та `Ctrl+Win+←`; ці комбінації працюють навіть тоді, коли діалог браузера радіостанцій закритий.

Щоб видалити станцію зі списку улюблених, виберіть її та натисніть кнопку **Видалити станцію** або клавішу `Delete`. Після видалення фокус та вибір автоматично переходять до наступної станції у списку. Якщо видалена станція була останньою, фокус переходить до попередньої станції. Якщо список стає порожнім, фокус переходить до кнопки «Відтворити».

### Експорт та імпорт улюблених

Вкладка «Улюблене» містить дві кнопки для резервного копіювання та відновлення списку станцій:

**Експортувати улюблені…** — зберігає весь список улюблених у файл. У діалозі збереження можна вибрати один із двох форматів:
- **JSON** (`.json`) — повна резервна копія, що зберігає назви станцій, URL-адреси потоків і всі метадані. Рекомендується для подальшого відновлення списку або його перенесення на інший комп'ютер.
- **Плейлист M3U** (`.m3u`) — стандартний формат плейлиста, сумісний із більшістю медіаплеєрів і радіододатків. Зверніть увагу, що M3U не зберігає всі метадані станцій, тому відновлення з M3U може містити менше деталей, ніж резервна копія JSON.

**Імпортувати улюблені…** — завантажує станції з раніше експортованого файлу JSON або M3U. Після вибору файлу пропонується вибрати спосіб додавання станцій:
- **Так (Об'єднати)** — додає імпортовані станції до наявного списку, не видаляючи поточні улюблені. Дублікати не додаються повторно.
- **Ні (Замінити)** — повністю очищає поточний список улюблених і замінює його вмістом імпортованого файлу.
- **Скасувати** — повертається до браузера без внесення жодних змін.

Після успішного імпорту список улюблених, список станцій для запланованих записів і список станцій таймера оновлюються автоматично.

### Зміна порядку в списку улюблених

Вибравши станцію на вкладці «Улюблене», натисніть клавішу «кома», щоб увійти в режим переміщення — пролунає звуковий сигнал. Перейдіть до потрібної позиції за допомогою клавіш зі стрілками, а потім знову натисніть клавішу «кома». Станція буде розміщена у вибраній позиції, а нове розташування одразу збережеться. Повторне натискання клавіші «кома» у цій же позиції скасує переміщення.

### Прямі комбінації клавіш для улюблених станцій

Кожна станція у вашому списку улюблених зареєстрована як окремий скрипт у діалозі «Жести вводу» NVDA, у категорії **Станції FreeRadio**. Ви можете призначити будь-яку комбінацію клавіш для будь-якої станції та натискати її з будь-якого місця — не потрібно спочатку відкривати діалог Браузер радіостанцій.

Щоб призначити комбінацію клавіш:

1. Відкрийте меню NVDA → Параметри → Жести вводу.
2. Розгорніть категорію **Станції FreeRadio**.
3. Знайдіть станцію за назвою, виберіть її та натисніть **Додати**.
4. Натисніть потрібну комбінацію клавіш і підтвердіть вибір.

Комбінація клавіш негайно активує станцію. Якщо пізніше станцію буде видалено з ваших улюблених, її запис зникне з категорії, а будь-яка призначена їй комбінація клавіш автоматично буде скасована NVDA. Коли до улюблених додається нова станція, вона одразу з’являється в категорії — діалог «Жести вводу» не потрібно відкривати знову.

### Додавання користувацької станції

Щоб додати станцію, якої немає в Браузері радіостанцій, скористайтеся кнопкою «Додати користувацьку станцію». У діалозі, що з’явиться, введіть назву станції та URL потоку, щоб додати її безпосередньо до списку улюблених. Власні станції можна відтворювати та змінювати їхній порядок так само, як і будь-які інші улюблені станції.

У цьому діалозі доступні дві додаткові кнопки:

- **Перевірити URL** — перевіряє введений URL потоку перед додаванням станції та оголошує, чи він доступний. Корисно, щоб виявити помилку в написанні або неробочу URL-адресу до того, як вона потрапить до списку улюблених.
- **Додати до каталогу Браузера радіостанцій…** — відкриває [сторінку подання до Браузера радіостанцій](https://www.radio-browser.info/add) у браузері за замовчуванням, щоб ви могли поділитися станцією з ширшою спільнотою Браузера радіостанцій, щойно підтвердите, що вона працює. Про те, що очікується у формі подання, див. розділ «Додавання станції до Браузера радіостанцій» вище.

### Аудіопрофіль станції

На вкладці «Улюблені» є дві кнопки для керування налаштуваннями звуку для кожної станції:

**Зберегти аудіопрофіль для цієї станції** — зберігає поточний рівень гучності, активні ефекти (хор, еквалайзер тощо) та значення підсилення еквалайзера як профіль, прив’язаний до цієї конкретної станції. Щоразу, коли починається відтворення цієї станції, її збережені налаштування гучності, ефектів та підсилення автоматично застосовуються, замінюючи загальні початкові налаштування .

**Очистити аудіопрофіль** — видаляє збережений аудіопрофіль з вибраної станції. Після очищення станція повертається до загальних налаштувань гучності, ефектів та підсилення еквалайзера. Ця кнопка активна лише тоді, коли вибрана станція вже має збережений профіль.

Обидві кнопки розташовані під списком улюблених і стають активними лише тоді, коли у списку вибрано станцію.

## Розпізнавання треків

Тричі натиснувши `Ctrl+Win+I`, запускається розпізнавання треків на основі Shazam для потоку, що відтворюється. Розпізнавання починається лише тоді, коли метадані ICY (інформація про трек, що транслюється станцією) недоступні; якщо метадані присутні, вони копіюються в буфер обміну.

Розпізнавання працює наступним чином: за допомогою ffmpeg із потоку витягується короткий аудіофрагмент, до нього застосовується алгоритм Shazam для визначення «відбитка», а результат надсилається на сервери Shazam. Якщо розпізнавання проходить успішно, назва треку, виконавець, альбом та рік випуску оголошуються NVDA та автоматично копіюються до буфера обміну. Якщо увімкнено опцію **Зберегти вподобані пісні у текстовий файл**, результат розпізнавання також додається до файлу `likedSongs.txt`.

**Аудіосигнали:** Два висхідних звукових сигнали лунають, коли розпізнавання починається, і два низхідних — коли воно закінчується. Короткий звуковий сигнал відтворюється кожні 2 секунди, доки процес триває.

**Вимога:** Потрібна наявність ffmpeg.exe. Якщо ffmpeg.exe знаходиться у папці додатка, він використовуватиметься автоматично; якщо в іншому місці — шлях можна вказати в Налаштуваннях. Завантажити ffmpeg можна з [ffmpeg.org](https://ffmpeg.org/download.html).

**Примітка щодо станцій, які вставляють рекламу:** деякі станції транслюють коротку рекламу під час кожного нового підключення до свого потоку, окремо від ефіру, який ви вже слухаєте. Розпізнавання уникає вибірки цієї реклами, повторно використовуючи наявне фонове з’єднання FreeRadio з потоком (те саме, що використовується для Тайм-шифту), замість того щоб відкривати нове, тому воно розпізнає те, що насправді грає, а не рекламу. Це працює автоматично і не потребує налаштування.

## Дзеркало аудіо

Комбінація клавіш `Ctrl+Win+M` дозволяє одночасно відтворювати потокове аудіо на другому пристрої відтворення. Це зручно, коли потрібно слухати аудіо одночасно на двох різних пристроях, наприклад на колонках і навушниках.

Після першого натискання з’являється діалог з переліком доступних пристроїв виведення. Як тільки пристрій обрано, починається дзеркальне відтворення, при цьому основне відтворення не переривається. Повторне натискання зупиняє дзеркалювання.

**Приклади використання:**
- **Динаміки + навушники** — Гість може слухати той самий потік в навушниках, поки ви слухаєте його через динаміки комп’ютера.
- **Налаштування запису** — Направте сигнал головного виходу на колонки, а сигнал другого виходу — на зовнішній записний пристрій або аудіоінтерфейс для зовнішнього запису.
- **Multi-room** — Відтворюйте треки одночасно через Bluetooth-колонку та вбудований динамік; для передачі звуку в іншу кімнату не потрібно додаткового програмного забезпечення.
- **Дистанційний моніторинг** — під час сеансу спільного використання екрана або віддаленого доступу до робочого столу як локальний, так і віддалений користувач можуть одночасно слухати один і той самий аудіопотік.

> **Примітка:** Функція дзеркального аудіо доступна лише тоді, коли активний бекенд BASS. Якщо під час дзеркального відтворення змінити гучність, обидва виходи оновлюються одночасно.

## Запис

Записи початково зберігаються у папці `Documents\FreeRadio Recordings\`. Назва файлу містить назву станції (або назву трека у режимі запису трека) та час початку запису. Папку для записів можна змінити у будь-який час: Меню NVDA → Налаштування → FreeRadio → **Папка для записів**. Оскільки механізм запису підключається безпосередньо до потоку, аудіо записується на диск у тому вигляді, у якому його отримано — обробка або повторне кодування не застосовується; якість запису ідентична якості трансляції.

**Миттєвий запис:** під час відтворення станції натисніть Ctrl+Win+E один раз. Натисніть знову, щоб зупинити. Відтворення при цьому не переривається.

**Запис трека:** Натисніть комбінацію клавіш `Ctrl+Win+E` **двічі** під час відтворення станції, яка транслює метадані ICY. Запис розпочнеться негайно, а його назва буде відповідати назві поточного треку. Коли трек зміниться, запис автоматично зупиниться, і NVDA оголосить назву збереженого файлу. Якщо ви хочете завершити запис до закінчення треку, знову натисніть `Ctrl+Win+E` двічі. Якщо поточна станція не транслює метадані ICY, запис трека недоступний, і NVDA повідомить вас про це.

**Запланований запис:** Відкрийте вкладку Запис у браузері радіостанцій. Виберіть станцію з улюблених, введіть час початку у форматі ГГ:ХХ і тривалість у хвилинах, виберіть один або кілька активних днів, потім оберіть режим повторення та режим запису:

**Активні дні:** Позначте один або кілька днів тижня. У режимі одноразового запису для кожного вибраного дня створюється окремий запис, встановлений на найближче настання цього дня. У режимі повторення запис виконується лише у позначені дні. Якщо жодного дня не вибрано, запис не обмежується конкретними днями.

**Режим повторення:**
- **Записати один раз** — створює одноразовий запис для кожного вибраного дня. Кожен запис встановлюється на найближче настання цього дня; якщо сьогоднішній час вже минув, запис автоматично переноситься на наступний тиждень.
- **Повторювати щотижня** — повторюється щотижня у вибрані активні дні до видалення зі списку розкладу.

**Режим запису:**
- **Запис під час прослуховування** — одночасне відтворення та запис. Для відтворення використовується один із програвачів у порядку пріоритетності: BASS → VLC → PotPlayer → Windows Media Player.
- **Тільки запис** — запис у фоновому режимі без відтворення звуку; механізм запису підключається безпосередньо до потоку.

NVDA сповіщає про початок і завершення запису. Якщо NVDA перезапускається під час активного запланованого запису, запис автоматично відновлюється під час запуску.

Як і функція розпізнавання треків, функції миттєвого запису та повторного використання записів треків використовують існуюче фонове з’єднання FreeRadio, якщо воно доступне, замість того, щоб відкривати нове, тому запис фіксує те, що насправді транслюється, навіть на тих станціях, які в іншому випадку подавали б нову рекламу для абсолютно нового з’єднання. Це не стосується запланованих записів у режимі **«Тільки запис»**, оскільки на момент їхнього початку жодна станція ще не веде трансляцію.

## Функція «Time-Shift» (перемотування прямого ефіру радіо)

Тайм-шифт дає можливість перемотувати станцію, яку ви зараз слухаєте, як відеореєстратор або магнітофон – зупинити момент, повернутися на кілька хвилин назад і наздогнати прямий ефір, коли забажаєте. Відтворення ніколи не припиняється: перемотування вперед і назад відбувається миттєво на тому ж аудіопотоці.

Функція **початково вимкнена**. Увімкніть її в меню NVDA → Параметри → Налаштування → FreeRadio → **Увімкнути буфер тайм-шифту (перемотування прямого радіо, ~10 хвилин)**, або миттєво перемикайте будь-коли за допомогою `Ctrl+Win+T`.

> **Примітка:** FreeRadio тепер постійно записує невеликий фоновий фрагмент поточного радіо — не тільки коли ця функція увімкнена — оскільки [Розпізнавання треків](#music-recognition) та [Запис](#recording) покладаються на це для уникнення реклами, описаного в цих розділах. Коли ця функція **вимкнена**, цей фоновий запис обмежується приблизно до останніх 45 секунд, а `Ctrl+Win+J`/`Ctrl+Win+K` залишаються недоступними — змінюється лише розмір буфера, а не те, чи він працює. Увімкнення цієї функції збільшує цей же запис до повного буфера перемотування на ~10 хвилин, описаного нижче.

### Як це працює

Після увімкнення FreeRadio безперервно записує потокову станцію у локальний буфер, що оновлюється у фоновому режимі, незалежно від звичайного відтворення. Буфер вміщує приблизно **останні 10 хвилин** аудіо; старіші дані автоматично видаляються з початку буфера у міру надходження нових, тому буфер завжди показує «недавнє минуле» відносно поточного моменту.

- **`Ctrl+Win+J`** — Перемотування назад на 15 секунд. При першому натисканні відбувається перехід із прямого ефіру в режим відтворення із затримкою, починаючи з моменту, що відстає від поточного ефіру на 15 секунд. Кожне наступне натискання переміщує вас ще на 15 секунд назад, аж до межі буфера.
- **`Ctrl+Win+K`** — Перемотування вперед на 15 секунд у режимі відтворення із затримкою. Як тільки ви досягнете межі прямої трансляції, відтворення автоматично переключиться назад на пряму трансляцію, а NVDA оголосить «Повернення до прямої трансляції» — вам не потрібно робити нічого додаткового, щоб відновити звичайне прослуховування.
- **`Ctrl+Win+T`** — Увімкнення або вимкнення всієї функції. Вимкнення цієї функції під час відтворення із затримкою негайно поверне вас до прямого відтворення та зупинить фонове записування поточної станції.

Фонове захоплення продовжується весь час, поки активний тайм-шифт, тому край прямого ефіру продовжує рухатися вперед, навіть коли ви слухаєте щось кількахвилинної давнини — точно як справжній DVR.

### Увімкнення та прогрів буфера

Буфер починає заповнюватися, щойно станція починає грати (при увімкненій функції) або в момент, коли ви вмикаєте функцію під час прослуховування станції. Тому перемотування можливе лише після того, як реально накопичено кілька секунд звуку — якщо натиснути `Ctrl+Win+J` одразу після переключення станцій, NVDA повідомить, що в буфері поки недостатньо звуку. Просто зачекайте кілька секунд і спробуйте знову.

Переключення на іншу станцію завжди перезапускає буфер для нової станції; буферизований звук попередньої станції видаляється.

### Підтримувані потоки

Тайм-шифт працює з тим самим діапазоном потоків, які вже підтримує FreeRadio:

- Звичайні HTTP/HTTPS-потоки (MP3, AAC, OGG тощо), включаючи сервери у стилі Shoutcast/Icecast.
- **HLS-потоки (`.m3u8`)** — FreeRadio вирішує основний плейлист станції, відстежує медіаплейлист і завантажує сегменти у фоні, щоб буфер залишався заповненим.

У рідкісному випадку, коли плейлист станції взагалі неможливо прочитати (наприклад, пошкоджений або недоступний маніфест `.m3u8`), NVDA повідомить, що перемотування недоступне для цієї конкретної станції.

### Вимоги та обмеження

- **Потребує бекенду BASS.** Тайм-шифт недоступний, коли BASS вимкнено і відтворення переходить на VLC, PotPlayer або Windows Media Player. Сам фоновий захват (а також забезпечуване ним уникнення реклами для Розпізнавання треків і Запису) у такому разі також недоступний, оскільки залежить від того самого з’єднання на основі BASS.
- Буфер розрахований приблизно на 10 хвилин; перемотати далі неможливо.
- Буфер прив'язаний до станції: зміна станції, зупинка відтворення або перезапуск NVDA очищають його й починають заново.
- Відтворення з тайм-шифтом використовує власний локальний файл буфера і не створює збереженого запису — якщо хочете зберегти звук назавжди, використовуйте також Миттєвий запис (`Ctrl+Win+E`).

## Таймер

Відкрийте вкладку «Таймер» у браузері радіостанцій (Alt+4). Можна додати два типи таймерів:

**Сигнал — увімкнути радіо:** Автоматично починає відтворення обраної станції з ваших улюблених у вказаний час. Оберіть станцію та введіть час у форматі ГГ:ХХ.

**Сон — зупинка радіо:** Зупиняє відтворення у вказаний час. Коли спрацьовує таймер, гучність поступово зменшується протягом 60 секунд, перш ніж відтворення зупиниться. Вибір станції не потрібен; просто введіть час.

Для обох типів, якщо вказаний час уже минув, дія планується на наступний день. Якщо на той самий час вже існує таймер (незалежно від типу), додавання нового заблоковано; користувач отримує повідомлення про конфлікт і пропозицію спочатку видалити наявний запис. Таймери, що очікують на виконання, перелічені у вкладці; виберіть один і натисніть кнопку «Видалити вибраний таймер», щоб скасувати його.

## Подкасти

FreeRadio містить повнофункціональний плеєр подкастів. Ви можете підписатися на будь-який RSS- або Atom-канал подкастів, переглядати епізоди, відтворювати їх, завантажувати та продовжувати відтворення з того місця, де ви зупинилися — і все це повністю доступно.

### Перехід на вкладку «Подкасти»

Відкрийте браузер радіостанцій за допомогою комбінації клавіш `Ctrl+Win+R` і перейдіть на вкладку **«Подкасти»** за допомогою `Ctrl+Tab` або `Alt+6`. Вкладка поділена на три основні розділи:

1. **Пошук та додавання** — верхній розділ для пошуку нових подкастів, що містить список попереднього перегляду, який показує епізоди того результату пошуку, який наразі вибрано.
2. **Підписки** — список каналів, на які ви підписані.
3. **Епізоди** — список епізодів для вибраного каналу з елементами керування відтворенням.

### Додавання каналу подкасту

Ви можете додати канал подкасту двома способами:

**За URL:**
- У полі **«Або введіть URL подкасту»** вставте повний URL RSS або Atom каналу (наприклад, `https://example.com/feed.xml`).
- Натисніть Enter або кнопку **Додати**.
- FreeRadio завантажить канал, перевірить його та додасть до ваших підписок. Якщо канал є дійсним, ви почуєте підтвердження з назвою каналу. Якщо перевірка не вдалася, з’явиться повідомлення про помилку з поясненням причини.

**За допомогою пошуку:**
- У полі **Пошук** введіть ключове слово (назву подкасту, тему або ім’я ведучого) та натисніть Enter.
- FreeRadio здійснить пошук у каталозі подкастів iTunes і відобразить відповідні подкасти у списку **Результати пошуку**.
- Вибір результату завантажує цей канал у фоновому режимі та показує його епізоди у списку **Епізоди у вибраному результаті** прямо під ним, тож ви можете переглянути, що насправді містить програма, перш ніж вирішити підписатися — див. [Попередній перегляд епізодів](#previewing-episodes-before-subscribing) нижче.
- Якщо вас влаштовує те, що ви бачите, виберіть результат і натисніть `Enter` або відкрийте його контекстне меню (клавіша «Контекстне меню» / `Shift+F10`, або клацніть правою кнопкою миші) та виберіть **Підписатися**, щоб додати його до своїх підписок. Канал додається негайно і з’являється у вашому списку підписок. Окремої кнопки «Додати вибране з пошуку» немає — клавіша `Enter` або контекстне меню є єдиним способом підписатися на канал із результатів пошуку, що дозволяє зберегти інтерфейс лаконічним та зручним.

> **Порада:** Ви також можете ввести URL каналу безпосередньо в поле пошуку — якщо він виглядає як дійсний URL, додаток спробує додати його як канал без пошуку.

**Контекстне меню для результатів пошуку:** клацніть правою кнопкою миші на результаті пошуку або виберіть його та натисніть клавішу «Контекстне меню» / `Shift+F10`, щоб відкрити меню з єдиною дією **Підписатися**, що еквівалентно натисканню клавіші `Enter` на результаті.

### Попередній перегляд епізодів

Перш ніж оформити підписку, ви можете прослухати епізоди подкасту безпосередньо з результатів пошуку. Щоразу, коли ви вибираєте подкаст у списку **Результати пошуку**, FreeRadio завантажує цей канал і показує його епізоди — назви та дати публікації — у списку **Епізоди у вибраному результаті**, розташованому нижче.

- Виберіть епізод у цьому списку попереднього перегляду та натисніть `Enter`, або відкрийте його контекстне меню (клавіша «Контекстне меню» / `Shift+F10`, або клацніть правою кнопкою миші) і виберіть **«Попередній перегляд»**, щоб розпочати відтворення у звичайному програвачі. Усі звичні елементи керування відтворенням (пауза, гучність, Перемотування тощо) працюють так само, як і на будь-якій іншій станції чи в будь-якому іншому епізоді.
- Під час попереднього перегляду епізоду у тому самому контекстному меню замість пункту **Попередній перегляд** з’являється пункт **Зупинити попередній перегляд** — виберіть його або натисніть клавішу `Enter` ще раз на цьому епізоді, щоб зупинити відтворення.
- Попередній перегляд не означає підписку на що-небудь; він призначений виключно для прослуховування перед тим, як ви приймете рішення. Сам список попереднього перегляду є тимчасовим — він замінюється, щойно ви виберете інший результат пошуку, і не зберігається ніде, на відміну від ваших фактичних підписок.

### Керування підписками

Після додавання каналів вони з’являються у списку **Підписки**. У кожному записі вказано назву каналу та кількість доступних епізодів.

- **Виберіть канал**, щоб переглянути його епізоди у списку. У текстовому полі **Деталі каналу** (тільки для перегляду), розташованому під списком підписок, показуються назва каналу, автор, опис, кількість епізодів та URL.
- **Оновити канал** — виберіть його та натисніть кнопку **Оновити канал** (доступно через контекстне меню, див. нижче), щоб завантажити найновіші епізоди. Усі канали також автоматично оновлюються у фоновому режимі під час відкриття вкладки «Подкасти», тому зазвичай ви бачите найновіші епізоди без ручного втручання.
- **Видалити канал** — виберіть його та натисніть клавішу `Delete` або скористайтеся контекстним меню, щоб видалити його зі своїх підписок. Перед видаленням вам буде запропоновано підтвердити дію.

**Контекстне меню для каналів:** клацніть правою кнопкою миші на каналі або виберіть його та натисніть клавішу «Контекстне меню» / `Shift+F10`, щоб відкрити меню з такими пунктами:
- **Оновити канал** — завантажити нові епізоди зараз.
- **Видалити канал** — видалити підписку.
- **Скопіювати URL каналу** — скопіювати URL каналу в буфер обміну.

### Перегляд та відтворення епізодів

Виберіть канал у списку підписок; його епізоди з’являться у списку **Епізоди** нижче. Для кожного епізоду показується:
- Номер епізоду (1 = найстаріший епізод у каналі, нумерація йде у порядку від найстарішого до найновішого).
- Дата публікації (якщо є).
- Назва.
- Префікс **«Прослухано»**, якщо епізод було повністю відтворено.
- Суфікс тривалості — загальна тривалість (якщо епізод ще не відтворювався) або відтворена/загальна тривалість (якщо епізод відтворювався частково).

**Відтворення:**
- Виберіть епізод і натисніть клавішу `Enter` або `Пробіл`, щоб розпочати його відтворення. Якщо епізод раніше відтворювався частково, відтворення продовжиться з того місця, де ви зупинилися.
- Рядок *не* оновлюється під час відтворення епізоду — це зроблено навмисно, щоб NVDA не повторювала оголошення рядка, поки ви перебуваєте на ньому. Позначка «Прослухано» та тривалість оновлюються одразу, щойно ви призупините епізод або він завершиться, тож інформація на екрані завжди точна саме тоді, коли це важливо; просто під час відтворення вона не оновлюється щосекунди.
- Використовуйте `F3` / `F4` на вкладці «Подкасти», щоб перейти до попереднього / наступного епізоду та негайно його відтворити. Ви також можете використовувати `←` / `→`, коли фокус знаходиться на списку епізодів, або `Ctrl+←` / `Ctrl+→` у будь-якому місці на вкладці «Подкасти» — обидва варіанти працюють однаково.
- Використовуйте `Shift+F3` / `Shift+F4`, щоб переходити між каналами без відтворення епізодів.
- Натисніть клавішу `Пробіл` під час відтворення епізоду, щоб призупинити або відновити відтворення.

**Відновлення відтворення:** FreeRadio автоматично зберігає вашу позицію в кожному епізоді подкасту — одразу після паузи або завершення епізоду, а також кожні 15 секунд у фоновому режимі, поки ви продовжуєте слухати, тому збій або неочікуване перезавантаження не призведе до значної втрати перебігу виконання. Якщо ви зупините або призупините відтворення та повернетеся пізніше, епізод відновиться зі збереженої позиції. Якщо ви відтворите епізод до самого кінця (протягом останніх 3 секунд), він позначиться як «Прослухано» і не відновиться — наступного разу він почнеться з початку, а префікс «Прослухано» з’явиться у списку.

**Контекстне меню епізодів:** Клацніть правою кнопкою миші на епізоді або виберіть його та натисніть клавішу «Контекстне меню» / `Shift+F10`, щоб відкрити меню з такими пунктами:
- **Відтворити епізод** — розпочати відтворення.
- **Завантажити епізод** — завантажити файл епізоду у папку із записами.
- **Скопіювати URL епізоду** — скопіювати прямий URL аудіо в буфер обміну.

### Завантаження епізодів

Виберіть епізод і натисніть кнопку **Завантажити епізод** (або скористайтеся контекстним меню). Епізод завантажиться у вашу папку із записами (Початково — `Documents\FreeRadio Recordings\`). Назва файлу формується на основі назви епізоду та виявленого розширення файлу (`.mp3`, `.m4a`, `.ogg` тощо). NVDA повідомляє про початок і завершення завантаження. Якщо файл уже існує, ви отримаєте відповідне повідомлення, і завантаження пропуститься.

### Фільтрування епізодів

Над списком епізодів розташоване поле **Фільтр**. Під час введення тексту список епізодів фільтрується в режимі реального часу, щоб показати епізоди, назва яких містить введений текст або номер яких точно збігається з ним — отже, введення `47` переносить вас безпосередньо до епізоду 47, навіть якщо «47» ніде не з’являється в його назві. NVDA оголошує кількість епізодів, що відповідають критеріям, після кожної зміни. Натисніть стрілку `Вниз` поруч із полем фільтра, щоб перемістити фокус безпосередньо до відфільтрованого списку.

### Деталі відтворення подкастів

Епізоди подкастів відтворюються за допомогою **бекенду BASS** (того самого механізму, що використовується для радіопотоків). Оскільки епізоди завантажуються поступово і мають можливість пошуку, під час відтворення подкасту ви можете використовувати комбінації клавіш для перемотування вперед/назад (`Ctrl+Win+J`/`Ctrl+Win+K`), щоб переходити вперед або назад по **5 секунд** за раз (замість 15-секундного перемотування, яке використовується для прямого ефіру). Позиція зберігається автоматично, тож ви зможете продовжити прослуховування пізніше.

Якщо бекенд BASS вимкнено (або він не працює), відтворення подкастів переходить на той самий ланцюжок зовнішніх програвачів (VLC → PotPlayer → WMP), що й для радіо, але **функції пошуку та відновлення не працюватимуть** у цьому випадку — епізод щоразу відтворюватиметься з початку. Щоб повною мірою насолодитися подкастами, залиште бекенд BASS увімкненим.

### Зберігання даних подкастів

Ваші підписки зберігаються у файлі `freeradio_podcasts.json` у папці конфігурації користувача NVDA. Позиції епізодів зберігаються окремо у файлі `podcast_positions.json` у тому ж місці. Обидва файли мають формат простого JSON, тому їх можна скопіювати для резервного копіювання або перенести на інший комп’ютер.

## Улюблені треки

Коли увімкнено функцію **«Зберегти улюблені треки у текстовий файл»**, інформація про треки, скопійована до буфера обміну потрійним натисканнями клавіш `Ctrl+Win+I`, також додається по рядках до файлу `Documents\FreeRadio Recordings\likedSongs.txt`.

На станціях, що транслюють метадані ICY, назва треку та виконавець зберігаються безпосередньо. На станціях без метаданих ICY результат розпізнавання Shazam зберігається у тому самому файлі — обидва джерела використовують один і той самий список. Файл створюється автоматично, якщо його ще немає; кожен запис додається в кінець файлу, а попередні записи ніколи не видаляються.

## Вкладка «Улюблені треки»

Вкладка **«Улюблені треки»** у браузері радіостанцій відображає всі треки, збережені у файлі `likedSongs.txt`. Список автоматично оновлюється з цього файлу щоразу, коли відкривається ця вкладка.

Поле **«Фільтр»** над списком дозволяє звужувати перелік показуваних треків у режимі реального часу. Введіть будь-яку частину назви треку або імені виконавця, і список миттєво оновлюватиметься з кожним натисканням клавіші. NVDA оголошує кількість відповідних результатів після кожної зміни. Натисніть стрілку `Вниз` біля поля фільтра, щоб перемістити фокус безпосередньо у список.

Вибір треку зі списку дає змогу виконати такі дії:

- **Відтворити у Spotify:** Намагається безпосередньо відкрити настільну програму Spotify. Якщо програма не встановлена, використовується веб-сайт Spotify, і автоматично починається відтворення першого результату.
- **Відтворити на YouTube (`Alt+O`):** шукає вибраний трек на YouTube та відкриває результати у початковому браузері.
- **Показати текст треку:** завантажує та показує текст вибраного треку. Тексти треків отримуються з [lrclib.net](https://lrclib.net) (безкоштовно, обліковий запис не потрібен). Під час пошуку, що виконується у фоновому режимі, озвучується коротке повідомлення «Завантаження тексту трека…». Якщо текст пісні знайдено, він відкривається у діалозі, доступному лише для читання, де ви можете прочитати його за допомогою NVDA та скопіювати до буфера обміну. Якщо текст пісні не знайдено, NVDA повідомляє про це. Під час завантаження кнопка тимчасово вимкнена, щоб запобігти повторним запитам.
- **Видалити (`Alt+M`):** Видаляє вибраний трек із файлу `likedSongs.txt` та оновлює список. Клавіша `Delete` також активує цю кнопку, коли фокус знаходиться на списку.
- **Оновити (`Alt+E`):** Перезавантажує список із файлу.

Кнопки «Spotify», «YouTube», «Показати текст пісні» та «Видалити» активні лише тоді, коли у списку вибрано реальний трек.

### Сервіс текстів треків

FreeRadio використовує [lrclib.net](https://lrclib.net) для отримання текстів треків — це безкоштовна відкрита база даних, яка не вимагає API-ключа чи облікового запису. Процес пошуку аналізує рядок назви треку, збережений у файлі `likedSongs.txt`, і послідовно застосовує все більш вільні запити, доки не буде знайдено текст треку:

1. Точний збіг за повним ім’ям виконавця та очищеною назвою (перед пошуком видаляються зайві суфікси, такі як «Remastered», «Live», або позначення року).
2. Точний збіг за повним ім’ям виконавця та оригінальною назвою (якщо під час очищення вона змінилася).
3. Точний пошук за першим ім’ям виконавця та очищеною назвою (для рядків із кількома виконавцями, таких як «Виконавець А & Виконавець Б»).
4. Неточний пошук за першим ім’ям виконавця та очищеною назвою.
5. Неточний пошук за необробленим рядком назви треку як крайній захід.

Якщо доступні звичайні тексти треків, вони показуються без змін. Якщо доступні лише синхронізовані за часом тексти у форматі LRC, часові мітки видаляються, а звичайний текст показується. Інструментальні треки позначаються як «не знайдено».

Потребує бекенду BASS. Вимкнено за замовчуванням — повні подробиці див. у розділі «Тайм-шифт» нижче. |

| Шлях до wmplayer.exe | За необхідності вкажіть тут шлях до Windows Media Player. |
| Шлях до PotPlayer | Якщо PotPlayer знаходиться в нестандартному місці, тут можна вказати повний шлях до виконуваного файлу. |
| Папка записів | Встановлює папку, в якій зберігаються записані файли. Якщо залишити поле порожнім, буде використане початкове розташування `Documents\FreeRadio Recordings\`. Кнопка «Огляд» дозволяє вибрати папку інтерактивно. Зміни набувають чинності одразу після збереження. |
| Вимкнути перевірку підключення до Інтернету перед відтворенням | Рекомендується для користувачів, які стикаються із затримкою перед початком відтворення станції. Також корисно, коли DNS заблоковано. |

## Вимкнути сповіщення

Якщо в налаштуваннях увімкнено **Вимкнути сповіщення**, NVDA вимикає наведені нижче автоматичні повідомлення:

- Назва станції, коли починається відтворення нової станції
- Зміни стану відтворення: відтворення, пауза, зупинка
- Події запису: початок, зупинка, завершення (миттєвий запис, запис трека та запис за розкладом)
- Оголошення про зміну трека в ICY, навіть якщо також увімкнено функцію **Автоматичне оголошення про зміну трека**

Нижченаведені повідомлення навмисно **не** підпадають під ці зміни: повідомлення про помилки, відгуки щодо улюблених треків (додано / вже є у списку), результати розпізнавання треків та повідомлення про оновлення.

Цей параметр можна увімкнути або вимкнути в меню NVDA → Параметри → Налаштування → FreeRadio, або миттєво в будь-який момент за допомогою жесту вводу, якому не призначено жодної комбінації (призначити такий жест можна в меню NVDA → Параметри → Жести вводу → FreeRadio). Після увімкнення або вимкнення NVDA один раз озвучить повідомлення «Сповіщення вимкнено» або «Сповіщення увімкнено» для підтвердження зміни.

## Автоматичне повідомлення про відстеження змін

Якщо в налаштуваннях увімкнено параметр **«Автоматичне оголошення зміни треку»**, FreeRadio приблизно кожні 5 секунд у фоновому режимі перевіряє потік метаданих ICY поточної станції. Коли трек змінюється, NVDA автоматично зачитує назву нового трека — натискання клавіш не потрібне.

Під час перемикання на нову станцію інформація про перший трек оголошується одразу після встановлення з'єднання. Якщо ви перемикаєтеся на станцію, яка не транслює метадані ICY, система не видає жодних звукових сигналів, а інформація про трек попередньої станції не повторюється.

Ця функція початково вимкнена, і її можна перемикати в меню NVDA → Параметри → Налаштування → FreeRadio.

## Відтворення

Додаток обирає механізм відтворення, дотримуючись такого порядку пріоритетів:

1. **BASS** — початковий механізм і основний. Окремої інсталяції не потрібно; він входить до складу додатка. BASS надсилає аудіо безпосередньо до аудіостеку Windows і показується в мікшері гучності Windows як самостійне джерело звуку під назвою «pythonw.exe», окреме від NVDA. Це означає, що аудіо FreeRadio передається по повністю окремому каналу відмінного від мовлення NVDA: радіо не обривається, не змішується та не зазнає впливу власних налаштувань аудіо NVDA під час мовлення NVDA. Користувач може регулювати гучність радіо незалежно від NVDA у мікшері гучності Windows. Підтримує HTTP, HTTPS та більшість вбудованих форматів потокового аудіо. Дзеркальне відтворення аудіо та пошук/відновлення подкастів доступні лише з цим модулем.
2. **VLC** — запускається, якщо BASS не працює. Автоматично шукається у типових місцях встановлення, папках профілів користувачів та системному PATH.
3. **PotPlayer** — запускається, якщо VLC не знайдено. Автоматично шукається у типових місцях встановлення.
4. **Windows Media Player** — використовується як крайній захід; вимагає наявності встановленого в системі компонента WMP.

Епізоди подкастів завжди відтворюються через BASS, якщо він доступний, оскільки BASS може відкривати потік як файл, у якому можна здійснювати пошук (навіть під час завантаження), і дозволяє точно відстежувати позицію та продовжувати відтворення. Якщо BASS вимкнено, подкасти відтворюються через ланцюжок зовнішніх програвачів, але функції пошуку та продовження відтворення не працюватимуть.

## Перевірка оновлень

FreeRadio автоматично перевіряє наявність нових версій через GitHub.

**Автоматична перевірка:** працює тихо у фоновому режимі через 15 секунд після запуску NVDA. Якщо знайдено нову версію, ви отримаєте сповіщення; якщо нічого не знайдено, повідомлення не показується.

**Ручна перевірка:** Можна запустити за бажанням у меню NVDA «Інструменти» → «FreeRadio» → **«Перевірити наявність оновлень…»**. При запуску таким чином результат оголошується навіть у тому випадку, якщо версія є актуальною.

**Якщо оновлення знайдено:** Відкриється діалог з номером версії та встановленою версією.

- Якщо у випуску на GitHub доступний файл `.nvda-addon` для прямого завантаження, з’являється кнопка **Завантажити та встановити**. Після підтвердження файл завантажується у фоновому режимі, NVDA повідомляє про початок завантаження, а потім автоматично відкривається власний діалог встановлення NVDA.
- Якщо посилання для прямого завантаження відсутнє, з’являється кнопка **Відкрити сторінку**, і сторінка випуску на GitHub відкривається у браузері.

**Щоб вимкнути автоматичні перевірки:** Вимкніть параметр **Автоматично перевіряти наявність оновлень** у меню NVDA → Параметри → Налаштування → FreeRadio.
